MOONLIT ECHOES
我的角色产品设计 / 全链路 Demo 开发
项目背景课程项目 · 独立产品实践
01 / THE PROBLEM

核心用户路径

提出问题 → 推荐牌阵 → 抽牌 → AI 解读 → 记录沉淀

02 / THE DECISIONS

项目亮点

01

后台与数据闭环

搭建 Web 运营后台，同步监控用户数据，打通“用户行为 → 数据沉淀 → 后台分析 → 产品优化”，为个性化推荐提供依据。

02

标签画像与个性化推荐

基于占卜、收藏、陪伴和每日指引等行为构建标签化用户画像，驱动灵感问题与牌阵的个性化推荐。

03

语音与图像多模态互动

设计 5 种性格的陪伴角色与主题皮肤，匹配不同语音音色；拓展基于占卜结果生成灵魂伴侣 AI 画像的玩法。

03 / THE OUTCOME

产出与结果

  • 全链路：微信小程序 + Django 后端 + MySQL 数据库 + Vue 运营后台
  • 拓展体验：语音播报、AI 生图、呼吸放松
  • 网页版静态演示：免注册体验核心交互

以上为完整项目设计与实现；当前网页体验为静态演示，采用预设回复、固定语音和示例画像，不实时调用模型或连接原项目数据库。
